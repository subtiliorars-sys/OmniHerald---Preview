# OmniHerald — Preview

Public **demo / preview** build for [OmniHerald](https://github.com/subtiliorars-sys/OmniHerald) — social draft workflow for the OmniTender stack: compose posts, review, and **human-approve before publish**.

## What this repo is

This repository holds a **sanitized, static web snapshot** (GitHub Pages) reserved for a public-facing preview — not the full private product codebase. The live console runs separately; this repo is the fleet catalog entry and future Pages mirror.

**Not included here:** source code, Zernio draft pipeline, auth, or production deploy config from the HQ repos.

## Main product (private)
